About CloudVault

A secure cloud file storage system that splits files into chunks, encrypts each chunk, and stores them in Amazon S3. This page is hosted on Amazon S3 and delivered over HTTPS through Amazon CloudFront.

How it works

1

Upload

The user selects a file and sends it to the Flask backend.

2

Split

The file is divided into fixed-size chunks (1 MB each).

3

Encrypt

Every chunk is encrypted with AES-256-GCM before leaving the server.

4

Store

Encrypted chunks go to a private Amazon S3 bucket; metadata is saved in a database.

5

Download

Chunks are fetched, decrypted, and reassembled in the correct order.

Security features

AES-256-GCM

Authenticated encryption detects any tampering with stored chunks.

Per-file keys

Each file has its own key, protected by a master key (envelope encryption).

Private bucket

S3 public access is blocked; only the app can read the chunks.

Least privilege

The IAM user can access only this one bucket.
